# ML Feature Store -- Real-Time Fraud Detection

A production-grade Machine Learning system that ingests **284,807 real credit card transactions**, streams them via **Kafka**, detects fraud using a **Random Forest model**, serves features with **sub-2ms Redis caching**, stores all results in **PostgreSQL**, and monitors everything with **Grafana + Prometheus** — all in a single `docker compose up`.

---

## System Architecture

```
creditcard.csv
     │
     ▼
 producer.py ──► Kafka (topic: transactions) ──► consumer.py
                                                       │
                                              POST /predict
                                                       │
                                              FastAPI api.py
                                               │         │
                                            Redis     PostgreSQL
                                         (cache)    (persistent)
                                               │
                                         Prometheus ◄── /metrics
                                               │
                                           Grafana
```

## Quick Start (5 Steps)

### Step 1 — Download the Dataset

Download `creditcard.csv` from Kaggle and place it in the `data/` folder:

```
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
```

Verify:
```bash
ls -lh data/creditcard.csv
# Should show ~150MB
```

---

### Step 2 — Train the Model

```bash
pip install scikit-learn pandas numpy joblib
python train.py
```

**What this does:**
- Loads 284,807 transactions
- Splits 80/20 with stratification (preserves 0.17% fraud ratio)
- Trains `RandomForestClassifier(n_estimators=100, class_weight='balanced')`
- Prints full classification report (F1, Precision, Recall, ROC-AUC)
- Saves `models/fraud_model.pkl` and `models/scaler.pkl`

**Expected output:**
```
[4/6] Training Random Forest...
       Training completed in ~45 seconds

Classification Report:
              precision    recall  f1-score
   Legitimate     1.00      1.00      1.00
   Fraud          0.97      0.83      0.90

ROC-AUC Score: 0.9821
```

---

### Step 3 — Start All Services

```bash
docker compose up --build
```

This boots all 9 services in dependency order:

| Service | Port | Startup Time |
|---|---|---|
| Zookeeper | 2181 | ~10s |
| Kafka | 9092 | ~30s |
| PostgreSQL | 5432 | ~15s |
| Redis | 6379 | ~5s |
| FastAPI | 8000 | ~40s |
| Producer | — | after API |
| Consumer | — | after API |
| Prometheus | 9090 | ~5s |
| Grafana | 3000 | ~10s |

Wait until you see:
```

fraud_api | Connected to Redis at redis:6379
fraud_api | Connected to PostgreSQL
fraud_api | INFO:     Application startup complete.
```

2. Go to **Dashboards → New Dashboard → Add Panel**
3. Select **Prometheus** as data source
4. Use these PromQL queries:

| Panel | Query |
|---|---|
| Request Rate | `rate(request_count_total[1m])` |
| Avg Prediction Latency | `rate(prediction_latency_seconds_sum[1m]) / rate(prediction_latency_seconds_count[1m])` |
| Fraud Detection Rate | `fraud_detection_rate` |
| Cache Hit Rate | `cache_hit_rate` |
| P95 Latency | `histogram_quantile(0.95, rate(prediction_latency_seconds_bucket[5m]))` |

## Airflow -- Nightly Model Retraining

The `dags/retrain_dag.py` DAG runs every night at **2:00 AM** and:

1. **extract_data** — pulls last 24hrs of transactions from PostgreSQL
2. **retrain_model** — retrains RandomForest on fresh data
3. **evaluate_model** — checks F1 ≥ 0.90 (fails if model is worse)
4. **deploy_model** — replaces `fraud_model.pkl`, sends email alert

To run Airflow locally:
```bash
pip install apache-airflow==2.8.0
export AIRFLOW_HOME=./airflow
airflow db init
airflow users create --username admin --password admin \
  --firstname Admin --lastname User --role Admin --email admin@example.com
airflow webserver --port 8080 &
airflow scheduler &
```
Then open http://localhost:8080 and enable the `fraud_model_retraining` DAG.

## Useful Commands

```bash
# View logs for a specific service
docker compose logs -f api
docker compose logs -f consumer
docker compose logs -f producer

# Check all service health statuses
docker compose ps

# Stop everything (keeps data volumes)
docker compose down

# Stop and DELETE all data (fresh start)
docker compose down -v

# Rebuild the API image after code changes
docker compose build api
docker compose up -d api

# Open a shell inside the API container (for debugging)
docker compose exec api bash

# Connect to PostgreSQL directly
docker compose exec postgresql psql -U frauduser -d frauddb

# Query recent fraud detections
docker compose exec postgresql psql -U frauduser -d frauddb \
  -c "SELECT transaction_id, amount, confidence, created_at FROM transactions WHERE is_fraud=true ORDER BY created_at DESC LIMIT 10;"

# Flush all Redis cache
docker compose exec redis redis-cli FLUSHALL
```

## Important Notes

- **creditcard.csv is NOT included** — download it from Kaggle (link above)
- **Run `python train.py` before `docker compose up`** — the API needs `.pkl` files to start
- **Grafana default password is `admin`** — change it in production
- **`fraudpass` is a demo password** — use a secrets manager in production (AWS Secrets Manager, Vault, etc.)
- The benchmark endpoint inserts 1000 rows into PostgreSQL — these will appear in your transactions table with `source='benchmark'`
